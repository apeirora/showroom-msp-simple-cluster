# charts/simple-cluster-system

Umbrella Helm chart for the four operators that live in the
`simple-cluster-system` namespace:

| Sub-chart | Source | Manager Deployment |
|---|---|---|
| `simple-cluster-operator`            | `simple-cluster-operator/dist/chart`            | `simple-cluster-operator-controller-manager` |
| `kind-cluster-operator`              | `simple-cluster-operator-kind/dist/chart`       | `kind-cluster-operator-controller-manager` |
| `simple-cluster-operator-openstack`  | `simple-cluster-operator-openstack/dist/chart`  | `simple-cluster-operator-openstack-controller-manager` |
| `simple-cluster-operator-ubuntu`     | `simple-cluster-operator-ubuntu/dist/chart`     | `simple-cluster-operator-ubuntu-controller-manager` |

`ubuntu-machines` operator lives in its own namespace and its own
chart — see `../ubuntu-machines-operator/`.

## Install

```sh
helm install -n simple-cluster-system --create-namespace \
  simple-cluster-system charts/simple-cluster-system
```

## Regenerate

The sub-charts under `charts/` are regenerated by

```sh
scripts/regen-helm-charts.sh
```

which runs `kubebuilder edit --plugins=helm/v1-alpha` in each operator
and copies the generated `dist/chart/` directory into this umbrella.
