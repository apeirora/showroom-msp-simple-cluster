# Code of Conduct

All members of this project's community must abide by the
[SAP Open Source Code of Conduct](https://github.com/SAP/.github/blob/main/CODE_OF_CONDUCT.md).

Only by respecting each other can we develop a productive, collaborative
community. Instances of abusive, harassing or otherwise unacceptable behaviour
may be reported by contacting a
[project maintainer](.github/CODEOWNERS).
